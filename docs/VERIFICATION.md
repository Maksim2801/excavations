# Результаты проверки изменений

Проверено 11 октября 2026 года.

- Python / pytest: 16 тестов пройдены, 13 интеграционных тестов пропущены, поскольку в среде проверки нет PostgreSQL/PostGIS. Есть предупреждение об устаревшем API в зависимости ReportLab.
- JavaScript: пройдены проверки переноса фильтров, сохранения false и нулевых значений, выбранных записей, восстановления шаблонов и изоляции/очистки кэша.
- Chromium / Playwright: пройден сценарий опись → экспорт → шаблон → карточка с GNSS → перетаскивание плана → перезагрузка без сети. Проверка использует контролируемые ответы API; ошибок JavaScript в браузере не обнаружено.
- Синтаксис файлов JavaScript и git diff --check проверены.
- Alembic: SQL миграций до head сформирован успешно. Применение миграций к действующей базе здесь не проверялось.
- Контрольное синтетическое изображение прошло пороги ошибки 2 мм и времени 3 секунды. Дополнительно проверено требование ручной калибровки при неразличимой границе линейки. Это не подтверждает точность на реальных снимках.

До эксплуатации следует выполнить интеграционные тесты с PostGIS и испытания на контрольных фотографиях по инструкции UPDATE.md. Для CI добавлен запуск с PostGIS и запрет успешного пропуска тестов при недоступной базе.

React и структура api/services/repositories/models сохранены. Сам документ диплома не изменён. Ограничения офлайн-работы и порядок согласования текста описаны в UPDATE.md.
